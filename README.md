## Installation

Clone or extract Abyss, then install its dependencies:
```bash
git clone https://github.com/inkitten/Abyss..My-operating-environment.git Abyss

cd Abyss
```
Then:
```bash
python -m pip install -r requirements.txt

python main.py
```
